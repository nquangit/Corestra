Cách thử prototype

Đây là mô phỏng bố cục extension, không phải tính năng đã tích hợp vào Burp. Mọi request, session và response đều là dữ liệu giả; không có kết nối tới API.

  1. Chọn 03 · Update order. Sửa "amount": 125000 thành số khác hoặc thay một placeholder bằng giá trị thử. Bấm Run selected.
  2. Chọn một lượt chạy cũ trong Run history. Response thay đổi, request bạn đang sửa vẫn giữ nguyên. Request đã gửi cho xem snapshot thực tế sau thay biến/inject.
  3. Mở Inject rules. Bỏ tick Apply inject rules for this request, rồi bật lại. Trạng thái Enabled riêng từng rule được giữ nguyên. Session injection vẫn là lớp riêng.
  4. Thử Lịch sử bên trái / bên dưới, chiều rộng 900–1440 px, mở Variables/Rules và kéo các thanh chia để cảm nhận chỗ chật.
  5. Whole flow hiện các request khác; click chỉ thay preview. Go to request mới đổi request đang sửa. Latest quay về kết quả mới nhất của request hiện tại.
  6. Run all mô phỏng tuần tự các bước đang bật. Stop dừng các bước tiếp theo. Thử Alice/Bob hoặc No session injection để xem request thực tế khác nhau.

Reload hoặc Reset demo sẽ về dữ liệu mẫu ban đầu. Không có persistence thật. Sidebar mặc định 258 px; cấu hình được thu gọn để ưu tiên editor.
