# Contributing to Corestra

Thank you for your interest in contributing to Corestra.

This project follows a centralized development model. Community contributions are welcome, while the official project direction and release process remain under the control of its maintainers.

## Contribution Process

1. Fork the official repository.
2. Create a dedicated development branch.
3. Implement your changes.
4. Add or update relevant tests and documentation.
5. Ensure all existing tests pass.
6. Submit a pull request to the official repository.

## Contribution Guidelines

- Keep changes focused and maintainable.
- Follow the project's coding standards and architecture.
- Provide clear commit messages.
- Explain the purpose and impact of your changes.
- Avoid unrelated modifications.
- Disclose any third-party code or dependencies introduced by your contribution.
- Do not include credentials, secrets, confidential information, or unauthorized proprietary code.

## Licensing Requirements

All contributions must comply with:

- [Restricted Source Contribution License](LICENSE)
- [Contributor License Agreement](CLA.md)

Forking and modifying the repository for contribution purposes is permitted.

Independent releases, unauthorized redistribution, commercial exploitation, and reuse of the project's protected code in other products are not permitted under the project license.

## Contributor License Agreement

All contributors must explicitly accept the Contributor License Agreement before their contributions can be merged.

## Project Governance

Project maintainers reserve the right to accept, reject, request changes to, or remove contributions.

Official releases are managed exclusively by authorized maintainers.
